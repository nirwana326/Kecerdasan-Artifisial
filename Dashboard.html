Catatan interpretasi dan metode: PRECTOTCORR adalah estimasi presipitasi terkoreksi dari NASA POWER yang bersumber dari MERRA-2, bukan pengukuran langsung penakar hujan di stasiun. Kategori 0, >0–<20, 20–50, dan >50 mm/hari digunakan sebagai kelompok analisis pada dashboard ini, bukan klasifikasi resmi intensitas hujan. Nilai -999 pada file sumber menandakan data hilang dan tidak dimasukkan ke statistik. Data ini hanya mencakup tahun 2022; hindari menyimpulkan tren jangka panjang dari satu tahun data.
Dataset ditanam langsung ke file HTML; CSV tidak perlu diunggah saat membuka dashboard. Chart.js dimuat melalui CDN sehingga koneksi internet diperlukan untuk menampilkan grafik.
